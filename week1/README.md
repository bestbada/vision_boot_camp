# 1주차 과제: 이미지 전처리 및 이상치 필터링 파이프라인

## 프로젝트 개요
Hugging Face의 `food101` 데이터셋에서 이미지를 스트리밍 방식으로 불러와, AI 모델 학습에 적합하도록 기본적인 전처리와 데이터 증강, 그리고 노이즈(이상치) 데이터를 걸러내는 파이프라인을 구현했습니다.

## 주요 기능 및 전처리 과정

### 1. [기본 문제] 이미지 기본 전처리 및 증강
* **크기 조정:** `cv2.resize`를 사용하여 모든 이미지를 모델 입력 규격인 224x224 크기로 통일했습니다.
* **정규화:** 픽셀 값을 0~255 정수에서 `0.0~1.0` 사이의 실수(`float32`)로 변환(Scaling)하여 모델 학습의 안정성을 높였습니다.
* **노이즈 제거:** `cv2.GaussianBlur`를 적용하여 이미지의 미세한 노이즈를 부드럽게 완화했습니다.
* **데이터 증강 (Augmentation):**
  * `cv2.getRotationMatrix2D`와 `warpAffine`을 활용해 이미지를 15도 회전시켰습니다.
  * `cv2.flip`을 사용하여 이미지를 좌우 반전 처리했습니다.

### 2. [심화 문제] 불량 데이터(이상치) 필터링
AI 학습에 방해가 되는 이미지를 사전에 차단하기 위해 아래의 두 가지 알고리즘을 적용했습니다.

* **너무 어두운 이미지 제거 (밝기 기준):** * 이미지를 Grayscale로 변환 후 `np.mean`을 통해 전체 픽셀의 평균 밝기를 계산했습니다.
  * 평균 밝기가 40 미만인 이미지는 제외(Skip) 처리했습니다.
* **객체 크기가 너무 작은 이미지 제거 (면적 기준):**
  * `cv2.Canny`를 통해 엣지를 검출하고, `cv2.findContours`로 물체의 윤곽선을 추출했습니다.
  * `cv2.contourArea`를 이용해 화면 내 윤곽선들의 픽셀 면적 총합을 구한 뒤, 그 크기가 150 미만으로 의미가 없는 파편 이미지들은 제외(Skip) 처리했습니다.
