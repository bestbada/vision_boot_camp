# 1주차: 이미지 전처리 및 이상치 필터링 파이프라인

## 개요
Hugging Face의 `ethz/food101` 데이터셋을 스트리밍으로 불러와, 품질이 낮은 이미지를 걸러내고 기본 전처리를 적용한 뒤 검수를 통과한 이미지 5장을 저장합니다.

## 처리 흐름

```
원본(RGB) → BGR 변환 → 224x224 리사이즈 → 흑백 변환
   → [필터 1] 평균 밝기 < 40 이면 제외
   → [필터 2] 윤곽선 면적 합 < 150 이면 제외
   → Gaussian Blur(5x5) → 15도 회전 → 좌우 반전 → 저장
```

### 이상치 필터링
- **너무 어두운 이미지**: 흑백 이미지의 평균 밝기(`np.mean`)가 40 미만이면 제외합니다.
- **객체가 너무 작은 이미지**: `cv2.Canny`로 엣지를 찾고 `cv2.findContours`로 윤곽선을 추출한 뒤, 면적 합(`cv2.contourArea`)이 150 미만이면 제외합니다.

### 전처리
- **리사이즈**: 모든 이미지를 224x224로 통일합니다.
- **노이즈 완화**: 5x5 Gaussian Blur를 적용합니다.
- **기하 변환**: 중심 기준 15도 회전 후 좌우 반전합니다. 별도 증강 샘플을 추가로 만드는 방식이 아니라, 한 이미지에 순서대로 적용합니다.
- **정규화**: 0~1 실수 변환을 구현했지만, 이미지 파일로 저장하기 위해 다시 0~255 정수로 변환합니다. 따라서 저장된 결과는 정규화되지 않은 8비트 이미지입니다.

## 실행

```bash
cd week1
pip install -r requirements.txt
python image_preprocessing.py
```

인터넷 연결이 필요하며, 실행이 끝나면 `preprocessed_samples/` 폴더가 생성됩니다.

## 결과
- `image_preprocessing.py`: 전체 파이프라인
- `preprocessed_samples/`: 필터를 통과한 224x224 흑백 이미지 5장
